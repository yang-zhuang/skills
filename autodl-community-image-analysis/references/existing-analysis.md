## 这些分析对本 skill 意味着什么

- **验「提速」**：直接继承测速三前提；不要把冷启动 / 单 prompt 复读的读数当结论。
  镜像名里的「500」先按 L0 定为「口径未定义」，再决定测什么指标。
- **验「高画质」**：继承「软控制 / 硬控制」的判据（见 capability-matrix.md）——
  画质需要固定输入输出对照，并写清是主观判断还是客观指标；不能从配置文件反推效果。
- **验「某版本 / 某框架」**：走 L1 静态信息 + L3 运行时事实，两者不一致时以 L3 为准。
- **跨镜像横评**：复用台账方法，但维度按当前候选临时组织，不照抄上一个项目的表。

## 边界声明

- 上表是**一次实证 + 一套方法**的索引，不是社区镜像的通用检查清单。
- 「官方示例」和「镜像名」都是精心挑过的，拿它当统一考题会有主场优势；候选文本与测试条件需自行定义。
- 新增镜像时只重跑受实例影响的层（L2~L4），L0 拆法与 L5 归档规约可直接复用。

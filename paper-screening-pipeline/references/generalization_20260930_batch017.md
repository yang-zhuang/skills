## 三、唯一新发现：§6 与 §4 的口径失同步（不是歧义，是同步遗漏）

### 现象

`2026.findings-acl.1395`（WenetSpeech-Wu，吴方言语音）论文自述三件事同时成立：

- 构建约 8000 小时语料库 →「数据集构建」类
- 发布六任务评测基准
- **`release a suite of strong open-source models trained on WenetSpeech-Wu`** → 确有训练动作

执行端判：`training_paradigm: []`（正确——按条款 4 情形②：有训练动作、但表内无任何范式
信号词）、`data_scale: "约 8000 小时"`（把该语料当作训练输入）。

评审判 `needs_fix`：条款 6 边界句「`不训练` 类论文（评测 / 综述 / **数据集构建**）→ 留空」
有两种读法 —— 按「作用域 = `training_paradigm` 取 `不训练`」读，本篇非 `不训练`，语料即
训练输入，填 8000 小时合规；按「数据集构建类一律留空」读，应留空。条款没写混合型以哪条为准。

### 根因：不是 §6 歧义，是上轮裁决只改了一半

上一轮裁决把 §4 的判据从「类型」改成了**动作**：

> §4（L76）：`不训练` = 文本正面描述了研究活动（评测 / 分析 / 综述 / 数据集构建 / 系统搭建）
> **且全文无任何训练动作**；`[]` 情形② = 确有训练动作但信号词全缺。

但 §6 那条边界仍写着**类型**：

> §6 边界一：`不训练` 类论文（评测 / 综述 / 数据集构建）→ 留空。

一句里「`不训练` 类」暗示以 paradigm 取值为准，「数据集构建」又像在列论文类型清单。
1395 恰好是「属数据集构建类 **且** 有训练动作」，两读打架。**§4 用动作、§6 用类型，两处
口径不一致** —— 这是上一轮同步只落在 §4、没同步到 §6 的结果，不是新歧义。

同样的病在上轮已发作过一次：`acl-long.489`（有训练动作但无信号词）掉在 §4 的缝里，记为
LESSONS R11。两次的共同点：**拿「论文类型 / 文本特征」当判定依据，而实际判定维度是
「训练动作的有无」。**

### 跨批判读（`cross_batch` 报 3 批，但方向相反）

| 批次 | 建议 | 方向 |
|---|---|---|
| b002 / acl-long.2100 | 数量必须与训练动词（train on / fine-tune on）显式关联才可填 | 收紧 |
| b002 / acl-short.20 | RL 场景：训练 prompt / rollout 条数计入，超参数不计 | 补例外 |
| b014 / findings-acl.203 | 显式覆盖数据集类论文 → 留空 | 收紧 |
| b017 / findings-acl.1395 | 留空与否以 `training_paradigm` 实际取值为准，训练语料计入 | 放宽 |

同条款、方向相反 → 按既定规则属人裁级。但**本轮与前几轮性质不同**：b002 与 b014 的
建议在上一轮裁决中**已被部分吸收**（RL 口径已写入 §6 边界二；数据集类留空已写成边界一），
b017 是对「吸收结果」的新反馈 —— 指出新写的边界一自身有歧义。所以不是三方各执一词。

### 建议裁法（与 §4 对齐，不新增规则）

把 §6 边界一的触发条件从**类型**改为 **`training_paradigm` 的实际取值**：

> 边界（2026-09-30 人批，2026-09-30 二次修订）：
> - **以 `training_paradigm` 的实际取值为准**：取值为 `不训练` → **一律留空**（数据集规模、
>   标注题量都不是训练数据量）；取值非 `不训练`（含 `[]`），且原文明确模型在该语料上训练
>   （如 `models trained on X` / `trained on <corpus>`）→ 该语料规模**计入**。
> - 若论文只披露语料总量、未单独披露训练切分规模 → 按语料总量填，保留原文的「约 / approximately」限定。

这条同时吸收 b002/acl-long.2100 的诉求（「数量须与训练动词显式关联」）—— 措辞里的
「原文明确模型在该语料上训练」就是那个关联要求。落点：RUBRIC.md 1 处 + EXTRACT.md L85 1 处。
**（2026-09-30 已人批：实际连同 §4 的四个同源复述点一次收口，共五处，见 `ruling_20260930_paradigm_activity.md`）**

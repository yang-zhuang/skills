# 裁决记录：条款「X 类活动 → 不训练」收口（2026-09-30 人批，第三轮）

> 第三轮人裁。前两轮见 `ruling_20260930_clauses_4_5_6.md`。本次不是新方向，是把第一轮已改对的动作判据
> **同步到同一条规则的其余复述点**——上一轮只改了 §4 一处，§6 仍是类型判据，两处口径打架。

## 一、问题

同一条规则（「评测 / 分析 / 综述 / 数据集构建 / 系统搭建 → `不训练`」）在 RUBRIC 与 EXTRACT 里共五处复述，其中四处只写了「X 类活动 → `不训练`」，没挂「且全文无任何训练动作」这个前置条件；§6 的下游边界更是直接按论文类型判。

触发样本：`2026.findings-acl.1395`（batch_017）同时满足「构建约 8000 小时语料库」「发布六任务评测基准」与 `release a suite of strong open-source models trained on WenetSpeech-Wu`。执行端按 §4 的动作判据落 `[]`（有训练动作、无范式信号词，情形②），评审端按 §6 的类型判据（数据集构建类 → 留空）要求 `data_scale` 留空 —— 同一篇论文，两处条款给出相反结论。

## 二、裁决

判据统一为**训练动作的有无**，不是论文属于哪一类：

| 落点 | 改后 |
|---|---|
| RUBRIC §4 表格 `不训练` 行 | 「正面描述了研究活动（…）**且全文无任何训练动作** —— 判据是训练动作的有无，不是论文属于哪一类」 |
| RUBRIC §4 边界（数据集 / 基准 / 系统） | 「全文再无其他训练动作时 → `不训练`；此类论文若同时出现训练动作（如 `release models trained on <corpus>`），按该训练动作判范式，不填 `不训练`」 |
| RUBRIC §4 边界（评测 / 分析 / 综述） | 补「（全文无任何训练动作）」 |
| RUBRIC §6 边界 | 由类型判据改为按 `training_paradigm` 的**实际取值**：`不训练` → 留空；其他（含 `[]`）且原文明确模型在该语料上训练 → 计入；只披露语料总量、未单独披露训练切分时按总量填，保留「约 / approximately」限定 |
| EXTRACT 高频错误表两行（`training_paradigm` / `data_scale`） | 同上两条同步 |

另去掉 §4 二分定义句末尾与新增边界重复的整句加粗（同一判据不再重复强调）。

## 三、为什么这是同步而不是新立法

§4 的 `不训练` 判据在上一轮（`ruling_20260930_clauses_4_5_6.md` §八）已改成动作判据。本次只是把同一条规则的其余复述点补齐 —— 「§4 用动作、§6 用类型」的分裂，就是上一轮同步只落一处的结果。

这与 `LESSONS.md` R11 是同一个病根：判定维度已经变了，复述点没跟上。R11 讲的是同节内新边界句与旧容错句合谋出第三态，本次讲的是**跨节、跨文档不同步**。

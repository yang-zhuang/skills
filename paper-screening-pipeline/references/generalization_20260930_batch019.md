## 三、新暴露（三条，均已达人裁阈值）

### 1. 条款 3 的字数界限自相矛盾（b003 + b019 两批同问题）

条款 3 取值写「30~40 字」，条款 0 给 ±4 容差 → 上限 44 字；但同节反例写「超过 60 字的复述性段落 ← 超长，违规」。45~60 字落在死区。

`acl-short.66` 的 `method_summary` 按条款 0 口径实为 **52 字**（48 汉字 + 4 个英文字串），比 44 多 8、比 60 少 8 —— 按取值该判 violation，按反例该判合规。

旁证（评审给出，已复核）：条款 3 自己的正例「用 LLM 自动合成指令数据替代人工标注，覆盖 3 个下游任务」按同口径只有 **25 字**，低于下限 30 —— 说明 30~40 从未被当硬界限执行。条款 3 的取值区间、容差、反例阈值三者互不相容。

建议二选一：

- ① 取值改为 **25~45 字**：原正例（25 字）合规、本篇（52 字）违规、60 字以上按反例加重。三处一致。
- ② 取值保留 30~40，反例阈值改为 **超过 44 字即违规**，60 字以上为加重情形；同时改写正例使其落在 26~44 内。

### 2. 条款 4「训练动作」的外延未定义（b006 + b008 + b019 三批同类）

`acl-short.66` 是探针类可解释性论文，摘要与正文都有 `train linear probes` / `Probes trained on deep representations`。按条款 4 字面，「`不训练` 要求全文无任何训练动作」不满足；但 `train` 不在任何范式族信号词内，正对应 `[]` 情形②。同篇因此可落 `不训练` 或 `[]`，且级联到条款 6（落 `[]` 则该篇 `approximately 4,000 math problems` 要计入 `data_scale`）。

建议在条款 4 的 `不训练` 行末补界定：

> 训练动作指**对论文所用模型的训练**（预训练 / SFT / RL）。为分析、探测或评测目的而拟合的辅助分类器 / 线性探针（`train linear probes`、`Probes trained on …`）不计为训练动作。

**但须与 b006 一并裁**：b006 主张「训练独立的预测器 / 分类器 / 回归头 → `SFT`」——与「探针不计入」方向相反。两者的分界应落在「该模型是不是论文方法的产物」：论文的核心方法就是训练一个判别模型 → 计 `SFT`；探针只是分析工具 → 不计。

两次执行端都填、两次评审都放过 —— 已形成一致做法，缺的是把它写进 rubric。建议在条款 5 补一句：

> 论文不训练模型、但方法施加于某现成模型（plug-and-play / 推理时干预 / 检索增强）时，该模型仍计为 `base_model`。

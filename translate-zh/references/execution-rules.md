# 翻译判断准则与硬边界

> 本文管「翻译执行时怎么判断、什么绝对不能做」。所有翻译执行者（主 agent 或外派
> sub-agent）必须完整遵守本文。分块、成本、隔离的机制性规则见 chunking-and-cost.md。

## 1. 输出格式

- 单个 markdown 文件
- **源文没有主标题（H1）时，补一行双语主标题**：`# 中文译题（English Original Title）`，
  并在「翻译说明」里注明"源文无主标题，译题依文中核心表述拟定"——
  这是授权动作，不是临机行为（实测三次触发后明文化，2026-10-07）
- 图片用 `![alt](url)`，保证直接打开就能渲染
- 代码块标注语言
- 末尾两节（如果有内容才写）：
  - `## 未确定的格式` —— 疑似标题/表格但没补全的行
  - `## 翻译说明` —— 需要人确认的取舍（术语怎么处理、哪句话有歧义）

## 2. 判断准则

### 2.1 不要机械翻译

先理解句意，再用中文技术写作习惯重组。允许：

- 调整语序、拆分长句、补出被省略的主语
- 被动改主动
- 长定语从句拆成短句（> 40 字的前置定语一定要拆）
- "we / our" 按语境译作「我们」或直接省略

**硬边界**（越过就是错，不是风格问题）：

- 不删减信息，不加原文没有的事实
- 不改数字、不改结论强度、不改时间
- 不翻译代码、命令、路径、文件名、库名

### 2.2 术语：读 `data/glossary.yaml` 并严格遵守

不在文档里背清单 —— 直接读文件，那里是唯一真相源。
遇到 yaml 里没有的术语，按 §2.3 的判据临时决定，**并在「翻译说明」里记一条**，
便于回头补进术语表。

**援引纪律（2026-10-07 新增）**：保留原文或按 fallback 处理时，只能援引
glossary 里**实际存在**的条目（哪一节、哪个词）。表里没有的词就如实写
"表中无此词，按 §2.3 判据临机保留/翻译" —— **禁止编造"按 pending 处理"
这类不存在的依据**（实测：执行者曾援引 pending 表里根本没有的 webhook 条目，
译文碰巧没错，但依据是假的；假依据会让主 agent 误判表已覆盖）。

### 2.3 判据：这个词到底翻不翻

一句话：**中文技术读者看到它，是不是一眼就懂、且不会产生歧义？**

- 是 → 保留原文（keep）
- 否，且是缩写 → 首次出现展开成 `中文（English Full Name, ABBR)`，全篇只展开一次
- 否，且不是缩写 → 翻译

反面例子：Transformer 翻成「变换器」会被误读成电力变压器，所以保留 Transformer。

### 2.4 首现通俗括注（gloss 机制）

`glossary.yaml` 里带 `gloss` 字段的词条，**首次出现**时写作：

```
译名（English 原词，即 gloss）
```

例：人在回路（human-in-the-loop，即每个关键步骤由人工审批）

全文只括注**一次**，后文一律只用译名。gloss 是写给不懂这个概念的读者的
「人话解释」，是否加由术语表逐条决定 —— 读者一眼就懂的词不加，加多了是噪音。
这个机制和缩写展开（expand）同构：都是首现给全、后文从简。

**维护权限**：主 agent **先行给出、默认生效**（先落 lexicon.md，稳定后提升进
glossary.yaml，篇末「翻译说明」列出本篇新增/变更词条）；用户是**否决制** ——
对已生效条目一句话即覆盖。必须先给出用户才有的反馈，且用户觉得翻得好时
不会专门反馈，所以**不等确认就落盘**。执行 agent 对 gloss 段**只读** ——
表里没有的词自己临机决定，但在回执和「翻译说明」里报告，由主 agent 落盘。
执行 agent 不直接改术语表，理由与「不能改说明文档」相同：多写者必然漂移
（实测：同一术语被译成「人在环路中」和「人在环路」）。

### 2.5 数字与单位

- 参数量一律保留符号：**7B 不写成 70 亿**
- 上下文长度、token 数同理：**128K 不写成 12.8 万**
- 货币、日期按中文习惯，但**数值本身不改**

## 3. 硬边界（绝不做什么）

1. 不翻译代码块内容、命令、路径、文件名、库名、API 名
2. 不删减原文信息，不补充原文没有的事实
3. 不改动数字、单位符号、链接
4. 不在译文里加自己的评论、总结、「译者注」（有疑问放「翻译说明」）
5. 原文有图片而译文丢失图片 = 失败，不是「简化」
6. 不确定的格式宁可不补，也不硬猜
7. **公式与数学符号不翻译**：`$$...$$` / `$...$` / `\(...\)`、LaTeX 源码、
   Unicode 符号（α β γ ≤ ≥ ∈ →）、公式编号 (1) (2)，一律字节级原样保留，一字不动。
   要翻的只是公式**周围的自然语言**："where α is the learning rate" → 「其中 α 为学习率」
   —— α 本身不翻，说明文字要翻。

# 微信不支持的 markdown 语法

渲染前必须改写，否则静默失效或排版塌陷。

## 表格

| 语法 | 问题 | 改写方式 |
| --- | --- | --- |
| 嵌套表格 | 微信不支持 | 拆成多个平级表格 + 小标题 |
| 表格含合并单元格 `\| \|` | `colgroup`/`thead`/`tbody` 被丢弃 | 取消合并，改用重复值 |
| 超宽表格（>4 列） | `overflow-x` 随容器被剥，无法横向滚动 | **拆行**：一行一个条目 |
| 单元格内换行 `<br>` | 部分版本失效 | 用分号或空格分隔 |

宽表格是微信排版最无解的限制——既不能横向滚动，也不适合长文阅读。
超过 4 列一律建议改为列表。

## 文本标记

| 语法 | 问题 | 改写方式 |
| --- | --- | --- |
| `~~删除线~~` | GFM 扩展，兼容性不稳 | `<span style="text-decoration: line-through;">…</span>` |
| `[^1]` 脚注 | 微信无脚注概念 | 文末小字列表 |
| `==高亮==` | 非标准 | `<span style="background-color: #fff3cd;">…</span>` |
| 6 级以上标题 | 层级过深 | 压到 3 级 |
| 任务列表 `- [ ]` | 复选框不渲染 | `- 未完成` / `- 已完成` |
| 引用式图片 `![][ref]` | 解析歧义 | 行内式 `![alt](path)` |

## 数学公式

`$...$` / `$$...$$` 不会被渲染。需要公式的两种处理：

1. 渲染器内置 KaTeX，产出静态 HTML（依赖外部 JS，微信会剥离 → 不可行）
2. **服务端渲染成图片**，再走正常上传流程 —— 推荐

## HTML 混排

markdown 里内嵌 HTML 极易踩坑，只保留白名单标签：

- 可用：`<span>` `<strong>` `<em>` `<br>` `<sub>` `<sup>` `<small>`
- 危险：`<script>` `<iframe>` `<style>` `<form>` `<object>` `<embed>`
- 无效：任何带 `class` / `id` / `style` 中 position 的容器

## 链接

| 类型 | 安全性 | 说明 |
| --- | --- | --- |
| 公众号文章链接（`mp.weixin.qq.com`） | 安全 | 可直接点|
| 站外域名 | **需后台白名单** | 未配置报"链接内容不属于当前公众号" |
| 锚点 `#id` | **失效** | `id` 属性被剥离 |
| `javascript:` | 失效 | 事件与伪协议被过滤 |

`wx-author` 会列出所有站外链接，需逐个确认是否已在白名单内。
